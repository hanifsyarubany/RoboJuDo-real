Changed 2026-09-18
Every stop is now the guard pose. A/Esc, Select/I and Start/G all do the same thing: legs and waist cut to zero stiffness at once, arms drive to the overhead head-guard pose over ~0.4s and hold. The old behaviours are gone — [SHUTDOWN] is no longer a raw unconditional torque cut, and [SOFT_STOP] no longer does a gentle ramp with the arms left alone.

The trade accepted in doing that: the guard pose is held by re-pushing gains every tick, so unlike the old [SHUTDOWN] it depends on the control loop still running. If the process dies or freezes mid-ramp, gains stay frozen where they were rather than dropping to zero. There is no raw torque-cut binding left on the pad.

Automatic fall detection is off on real hardware. do_safety_check is False everywhere now, so nothing stops the robot on its own — stopping it is entirely the operator's call using the buttons below.

The same bindings as the diagram above, always on screen. Keyboard equivalents (RoboJuDo also runs off a plain keyboard) are listed under each control.

Different config, same RB+X-adjacent keys: in g1_unified_loco_kick_amo (the AMO hand-off build, not the default one mapped above), RB+D-pad Left/Right switch [POLICY_SWITCH] between AMO and the unified policy. That's a separate feature from Cycle Skill — the default config keeps Cycle Skill on RB+X specifically so the two never collide.

Sim reads a generic USB/Bluetooth pad via SDL (JoystickCtrl). On the real G1 the onboard Unitree remote is used instead (UnitreeCtrl) — same layout, LB/RB just arrive as L1/R1 on the wire, which is all the Sim/Real switch above relabels.

In sim, a stop no longer closes the viewer — the window stays open with the robot held in the guard pose. Ctrl+C in the terminal is how you actually exit. The sim-only keyboard stops P/O/R were folded into the same guard pose too, so they are now exact duplicates of G.

How firmly the arms reach the pose is tunable per run without editing anything: --guard-arm-kp / --guard-arm-kd on run_pipeline_prepared.py (default 20/2). The default is deliberately weak so an arm meeting the ground or an obstruction doesn't transmit full force; raising it trades that protection for a pose that lands faster and more completely, which matters most when the stop is hit mid-kick-strike.
